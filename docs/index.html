looped Transformers, cooked in a small kitchen

NVIDIA released the looped model Dory1.0-4B with no tech report. This lab rebuilds what the older, smaller looped models already know - Huginn, Ouro, Loopie - runs the new kid locally on an RTX 4070, and measures loop counts hands on.

What the lab learned so far

The one sentence version: going from 1 to 2 loops buys the most accuracy (+15 points on a 72 task combined eval) while the next loops mostly just cost speed. Algorithm style tasks (stack programs) are the loop sensitive kind, easy arithmetic almost never needs a loop.
